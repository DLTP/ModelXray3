Problem Statement

Let's make an AI model for a simple calculator which can do 4 basic operations (+, -, *, /).

// Raw Data Example:
Input: [5, 2, '+'] → Target: [7]
Input: [10, 5, '/'] → Target: [2]
Input: [3, 4, '*'] → Target: [12]
Input: [8, 3, '-'] → Target: [5]

We are selecting the following matrix sizes for our neural network: Input layer (1x6), First weights (6x64), First bias (64x1), Second weights (64x32), Second bias (32x1), Third weights (32x1), Third bias (1x1).

🧠 Why 64-width Matrices and 3 Layers?

We are choosing a 64-width matrix (64 neurons) for the first layer because higher resolution allows the model to map the input space—which consists of mixed data types (numbers and encoded operations)—into a highly detailed mathematical representation.

We use 3 layers because it takes depth to learn complex logic: Layer 1 extracts the features (identifying the operation), Layer 2 compresses and processes the logic (performing the math), and Layer 3 projects the final answer.

01. Architecture: The High-Res Brain

Internal Mechanics

Our AI model isn't just a formula; it's a structural network. We use a 64-neuron input layer followed by a 32-neuron feature extraction layer. This density allows the model to capture subtle decimal variations in mathematical operations.

🛠️ Dynamic Resolution

Why 64 neurons? Higher resolution in the first layer allows the model to map the input space (normalized numbers and operations) into a high-dimensional feature space before calculating the result.

💡 One-Hot Encoding

Operations (+, -, *, /) are encoded as distinct binary toggles: [1,0,0,0]. This ensures the model treats categorical data (ops) mathematically without assuming a numerical relationship between them.
